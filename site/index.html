Keelbook The vulnerability register for the EU Cyber Resilience Act, per product and release.

Your data

Your SBOM file and your register never leave this computer. To find vulnerabilities, Keelbook sends only the names and versions of the components (for example "openssl 3.4.2") to public vulnerability databases (OSV, and NVD if you tick it), the same way you would search for them yourself. Keelbook never reports anything to ENISA, the EU cybersecurity agency: if the CRA requires a report, you send it yourself.
